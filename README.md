## 🔷 Featured Projects

### [Talent Hub](https://play.google.com/store/apps/details?id=com.ostontechnology.talent_hub_app)
> Mobile platform for Nepali students: mentors, opportunities and study guidance. On Google Play, in active development.

- Flutter app with a Supabase backend (PostgreSQL, Auth, Storage, Edge Functions)
- Personalized Study, Job and Business tracks, mentor profiles, in app intro videos and username search
- Crashlytics crash reporting and CI, with the production launch in preparation

---

### [MargaAI Nepal](https://github.com/manusharansah/Margadarshan)
> GIS powered delivery route optimization for Nepal's hilly, disaster prone terrain.

- Yen's K shortest paths and a Held Karp TSP solver over a cost model of slope, road type, hazard score and distance
- Gemma as a reasoning layer that picks among feasible plans and explains the choice, with all costs computed deterministically
- FastAPI + NetworkX backend with a React 19 + TanStack + Leaflet map interface

---

### [EchoNote](https://github.com/EchoNote)
> AI meeting transcription and minutes generator, built at the National AI Hackathon 2026 (Team Zapped).

- Whisper transcription and a local Ollama LLM that generates structured meeting minutes
- In app markdown editor with live regeneration and branded PDF export through ReportLab
- FastAPI + SQLAlchemy + SQLite backend with JWT authentication, React + TypeScript frontend

---

### [VidyaChain](https://vidyachain.vercel.app)
> Blockchain based certificate verification, built at KU Hackfest 2025.

- Tamper resistant credential verification to combat certificate fraud in Nepal
- Instant verification without a central authority
- Certificate issuance and revocation restricted to the issuing authority

---

### [SajiloSewa](https://github.com/manusharansah/protobytes-2.0-team-VoiceNepal)
> Voice assistant for government services, built at Protobytes Hackathon 2.0 (PACE, ACEM).

- Guides citizens through government services using natural language
- Designed for rural and less tech savvy users

---

### [Insurance Premium Category Predictor](https://github.com/manusharansah/FastAPI/tree/main/insurance_premium_prediction_project)
> ML-powered REST API — fully containerized and production-ready.

- FastAPI + Pydantic backend with Swagger documentation
- scikit-learn classification model exposed via REST endpoints
- Streamlit frontend communicating with FastAPI backend
- Docker containerized deployment (FastAPI:8000 · Streamlit:8501)

---

### [Student Performance Prediction Model](https://github.com/bishal-777/Student-Performance-Predictor)
> End-to-end ML regression pipeline on academic and behavioral data.

- Data cleaning → EDA → feature engineering → model evaluation
- Tech: Python · scikit-learn · Pandas
